# ITOS Academy

ITOS Academy es una aplicación web para la gestión de cursos de capacitación corporativa. Permite administrar usuarios, cursos, materiales, evaluaciones, preguntas y avances de aprendizaje, aplicando permisos según el rol del usuario.

## Tecnologías utilizadas

### Front-end
- ReactJS
- React Router
- Hooks
- Context API
- Axios
- CSS personalizado

### Back-end
- Node.js
- Express
- MySQL
- Swagger
- Multer
- bcryptjs

## Módulos principales

- Login de usuarios
- Dashboard
- Gestión de usuarios
- Gestión de cursos
- Carga de materiales PDF y video
- Aprendizaje por materiales
- Evaluaciones en modal
- Reintentos controlados
- Gestión de preguntas manual y por CSV
- Documentación API con Swagger
